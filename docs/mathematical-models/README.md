# Mathematical Models

This directory contains formal specifications for the project's core financial models.

- [`capm.md`](capm.md): excess-return regression, beta, alpha, CAPM-implied expected return and diagnostics.
- [`portfolio_optimization.md`](portfolio_optimization.md): mean-variance portfolio objectives, constraints, Monte Carlo weight sampling and efficient frontier.

These documents define intended mathematics; empirical claims must wait until the implementation has been tested and the results generated.
